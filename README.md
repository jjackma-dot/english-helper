# English Helper

휴대폰(안드로이드 크롬·아이폰 Safari)에 설치해서 쓰는 영어 학습 웹앱(PWA)입니다. 빌드 과정 없이 HTML·CSS·JavaScript만으로 만들었고, GitHub Pages로 무료 배포합니다.

| 탭 | 기능 |
| --- | --- |
| **AI 회화** | 버튼 한 번으로 **앱 안에서 AI 튜터와 바로 영어 음성 대화**(Gemini Live, 무료 키 필요 — 받아쓰기·교정 카드·단어장 저장, 버튼이나 목소리로 튜터 말 끊기). 튜터 요청문을 휴대폰의 **ChatGPT·Gemini 앱**으로 보내거나 Gemini Live를 바로 열 수도 있음 |
| **사전** | 한영·영한 자동 판별, 한국어 뜻, 영영 풀이, 예문(+해석), **발음 듣기**(원어민 음성·TTS·느리게), **이미지 검색**(필요할 때만), 음성 검색, 네이버·다음·Cambridge·YouGlish 바로가기 |
| **번역** | 텍스트 번역, **실시간 통역**(말하면 문장마다 바로 번역, 소리로 읽기), **녹음 번역**(최대 5분 녹음 → 받아쓰기·번역, WAV 저장), **사진 번역**(카메라로 찍거나 갤러리·화면 캡처에서 고르거나 공유받은 사진(안드로이드)의 글자를 읽어 번역, Gemini 키 필요) |
| **OTT** | 자막 없이 보다가 **"방금 뭐라고?"** 한 번 → 최근 10~30초 대사 받아쓰기·해석·표현 설명(Gemini), 느리게 다시 듣기 · 이어폰으로 볼 때는 **들린 대로 말하기·적어서 묻기**로 대사 짐작 · (선택) 자막 파일로 따라가며 되감기 |
| **단어장** | 사전·번역·OTT에서 저장한 단어와 대사, 뜻 가리기, AI 튜터 복습 연결, JSON 내보내기/가져오기 |

## 먼저 알아 둘 점 (기술적 제약)

- **넷플릭스·웨이브 앱은 다른 앱이 화면에 버튼을 띄우거나, 재생을 되감거나, 자막을 읽을 수 없습니다** (DRM과 앱 간 보안 격리). 그래서 OTT 기능은 **휴대폰 마이크로 스피커 소리를 듣는 방식**("방금 뭐라고?")이 기본이고, 자막 파일을 불러와 재생 시간에 맞춰 따라가는 방식은 선택입니다.
- **웹앱은 ChatGPT 음성 모드나 Gemini Live를 자동으로 켤 수 없습니다** (안드로이드·아이폰 모두 웹 페이지가 다른 앱의 음성 화면을 직접 여는 것을 막습니다). 그래서 손을 대지 않고 바로 이어지는 음성 대화는 **앱 안의 음성 튜터**(내 Gemini 무료 키로 Gemini Live API 사용)로 합니다. ChatGPT·Gemini 앱은 보조로, 요청문을 공유 시트로 보내거나 주소로 열어 줍니다(ChatGPT는 요청문이 자동으로 보내지고, Gemini Live는 화면만 열리므로 안내하는 첫 문장을 말하면 됩니다).
- **웹앱은 휴대폰 음량을 바꿀 수 없습니다.** 음성 대화를 시작할 때 음량을 올리고 끝나면 내리고 싶다면 갤럭시 **모드 및 루틴**에서 "앱을 열었을 때: English Helper → 미디어 음량"을 정해 두세요(앱을 닫으면 대개 원래 음량으로 돌아감). 대화 중에는 휴대폰이 통화처럼 소리를 처리해서 볼륨 버튼이 통화 음량을 바꿀 수 있습니다.
- 사전·번역·이미지는 **인터넷이 필요**합니다. 앱 화면과 저장한 자막·단어장은 오프라인에서도 열립니다.

## 배포 (GitHub Pages)

1. 이 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다 (한 번만).
2. 변경 사항을 `main` 브랜치에 합치면 `.github/workflows/pages.yml`이 테스트를 돌린 뒤 자동 배포합니다.
3. 주소: **https://jjackma-dot.github.io/english-helper/**

배포할 때 버전 표시(`__BUILD__`)가 "앱 파일이 마지막으로 바뀐 날짜-내용 해시"(예: `20261008-1a2b3c4d`)로 바뀝니다. 앱 파일이 실제로 바뀐 경우에만 버전이 달라져서, 이미 설치한 휴대폰에 "새 버전이 있습니다 → 업데이트" 안내가 뜹니다. README·테스트만 고친 배포에서는 안내가 뜨지 않습니다. 앱을 끄지 않고 며칠씩 백그라운드에 두어도, 화면에 돌아올 때 한 시간에 한 번 새 버전을 확인합니다(음성 대화·OTT 듣기·자막 따라가기 중이면 안내는 그게 끝난 뒤에 뜹니다).

## 휴대폰에 설치 (안드로이드 크롬)

1. 크롬으로 위 주소를 엽니다 (카카오톡에서 링크를 눌러 열렸다면 메뉴의 "다른 브라우저로 열기" → 크롬).
2. 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가** (화면 위쪽 "앱 설치" 버튼이 보이면 그걸 눌러도 됩니다).
3. (안드로이드만) 설치하면 다른 앱의 **공유 → English Helper**로 단어(→ 사전)나 문장(→ 번역), **사진**(갤러리·카메라·화면 캡처 → 사진 번역)을 바로 보낼 수 있고, 앱 아이콘을 길게 누르면 사전·번역·OTT 바로가기가 나옵니다.
   - 공유받기는 설치한 앱에서만 됩니다(앱 안의 서비스 워커가 받음). 사진 공유가 추가된 버전으로 **업데이트**한 뒤에도 공유 목록에 사진 공유가 바로 안 보일 수 있습니다. 휴대폰이 앱 정보를 새로 받는 데 시간이 걸리기 때문이며(하루쯤), 급하면 앱을 지우고 다시 설치하면 바로 바뀝니다(지우기 전에 단어장 탭의 내보내기로 백업해 두면 안전합니다).
   - 공유했는데 오류 화면이 나오면, 앱을 한 번 열고(**업데이트** 버튼이 보이면 누른 뒤) 다시 공유하세요.
4. 처음 마이크를 쓸 때 권한을 허용하세요.

## 아이폰에 설치 (Safari)

1. **Safari**로 위 주소를 엽니다 (카카오톡에서 링크를 눌러 열렸다면 메뉴의 "다른 브라우저로 열기" → Safari). 아이폰의 다른 브라우저보다 Safari를 권장합니다.
2. 주소창 옆(또는 아래쪽)의 **⋯** → **공유**를 누릅니다(**공유** 버튼이 바로 보이면 그 버튼을 눌러도 됩니다). 나온 목록을 아래로 내려 **홈 화면에 추가** → **웹 앱으로 열기**가 켜져 있는지 확인 → **추가**. (화면 위쪽 **앱 설치** 버튼을 누르면 같은 순서가 나옵니다.)
3. **홈 화면 아이콘으로 열어** 설정에서 Gemini 키를 다시 넣습니다. Safari와 홈 화면 앱은 저장 공간이 따로라 Safari에서 넣은 키·단어장은 옮겨지지 않습니다(단어장은 Safari에서 내보내기 → 앱에서 가져오기).
4. 처음 마이크·음성 인식을 쓸 때 권한을 허용하세요.

안드로이드와 다른 점:
- **공유받기**(다른 앱의 공유 → English Helper)와 **앱 아이콘 길게 눌러 바로가기**는 안드로이드에서만 됩니다. 사진은 앱 안의 **카메라로 찍기**나 **사진 고르기**로 번역하세요.
- **저장 공간**: Safari 탭과 홈 화면 앱은 따로입니다. Safari 탭에서 쓰면 7일 넘게 열지 않을 때 키·단어장·기록이 지워질 수 있으니 홈 화면 앱으로 쓰세요(홈 화면 앱은 이 규칙에서 빠집니다).
- **음성 인식**(사전 음성 검색·실시간 통역·기본 음성 모드)은 아이폰의 Siri·받아쓰기 기능을 씁니다. Siri(설정 → Siri, 또는 Apple Intelligence 및 Siri)와 받아쓰기(설정 → 일반 → 키보드)가 모두 꺼져 있으면(스크린 타임 제한 포함) 쓸 수 없습니다. 또 홈 화면 앱에서는 음성 인식이 막힐 수 있습니다. 그럴 때는 같은 주소를 Safari에서 열어 쓰세요. Gemini 키가 있으면 음성 인식이 필요 없는 **녹음**(녹음 번역)과 **AI 회화의 Gemini Live 음성 대화**도 쓸 수 있습니다(둘 다 키 필요).
- **OTT "방금 뭐라고?"**: 아이폰에는 분할 화면이 없고, 같은 아이폰에서 넷플릭스를 보며 **듣기 시작**을 누르면 넷플릭스 소리가 멈출 수 있습니다. TV 등 다른 기기로 볼 때 쓰거나, 이어폰으로 볼 때처럼 **들린 대로 말하기·적어서 묻기**를 쓰세요.
- **실시간 자막**: 설정 → 손쉬운 사용 → 실시간 자막 (기종·언어에 따라 없을 수 있음).
- **사진 속 글자 번역(키 불필요)**: 카메라·사진 앱의 **텍스트 인식(라이브 텍스트)** → 번역. 아이폰 17은 **카메라 컨트롤**을 길게 눌러 **시각 지능** → 번역도 됩니다(Apple Intelligence 필요).
- **AI 회화를 스피커로** 하면 튜터 목소리가 작게 들릴 수 있습니다. 이어폰을 권장합니다.
- **단어장 내보내기**와 녹음 번역의 **파일 저장**은 공유 시트로 열립니다. **파일에 저장**·에어드롭·카카오톡 등을 고르세요.
- **영어 발음 음성**: 아이폰 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 영어에서 더 자연스러운 음성을 내려받은 뒤, 앱 설정의 **영어 음성**에서 고르세요. 앱에서 고르지 않으면 아이폰에 설정된 기본 영어 음성으로 읽습니다.

아이폰에 맞춘 동작 (안드로이드는 그대로):
- **읽어 주기**: 아이폰은 버튼을 누른 순간이 아니면 첫 읽기 소리를 내지 않아서, 대화 시작·번역·통역 버튼을 누를 때 기기 음성을 미리 준비해 둡니다(기본 음성 모드의 답, 번역 자동 읽기가 들리게).
- **음성 인식**이 아무 반응 없이 멈추면 알아채고 다시 듣거나 다시 누르라고 알려 줍니다. 한동안 말소리가 없으면 듣기를 멈춥니다.
- **AI 회화** 중 전화·Siri 등이 소리를 가로채면 대화를 잠시 멈추고, 소리가 돌아오면 이어 갑니다.
- 무음 모드에서도 OTT **느리게 다시 듣기** 소리가 나게 했습니다.
- 녹음 파일 저장·단어장 내보내기는 공유 시트로 엽니다(위 참고).

## 여러 기기·가족과 함께 쓰기

- **기기마다 따로 동작합니다.** 검색·번역 기록, 단어장, 설정·Gemini 키, 자막 보관함, 저장된 AI 풀이는 모두 그 기기 안에만 있고 동기화되지 않습니다(서버 없음). 아이폰은 Safari 탭과 홈 화면 앱도 서로 따로입니다.
- **단어장 옮기기**: 단어장 탭 **내보내기** → 파일을 카카오톡·에어드롭 등으로 보내기 → 받는 휴대폰의 단어장 탭 **가져오기**(이미 있는 단어는 건너뜀).
- **Gemini 키**는 기기마다 설정에서 넣습니다. 같은 Google 프로젝트의 키를 여러 기기에서 쓰면 **하루 무료 한도를 함께** 씁니다(한도는 키가 아니라 프로젝트 단위). 한 기기에서 다 쓰면 다른 기기에서도 그날(미국 태평양 시간 자정까지) 한도 초과가 납니다.
- **Gemini API는 약관상 만 18세 이상만 쓸 수 있습니다.** 18세 미만 자녀의 기기에는 키를 넣지 말고, 키 없이 되는 기능(사전·번역·실시간 통역·단어장·자막 파일로 따라가기)과 **AI 회화 → 다른 앱으로 연습**(ChatGPT·Gemini 앱, 각 앱의 연령 정책을 따름)을 쓰세요.
- 무료 등급에서는 보낸 내용(음성 포함)을 Google이 서비스 개선에 쓰고 사람이 검토할 수 있습니다. 민감한 내용은 보내지 마세요.
- 앱 주소는 카카오톡 링크를 눌러 그대로 쓰지 말고 **안드로이드는 크롬, 아이폰은 Safari**로 열어 설치하세요. 카카오톡 안의 브라우저는 설치가 안 되고 저장 공간도 따로입니다.

## 기능별 사용법

### AI 회화 (앱 안 음성 튜터 + ChatGPT·Gemini 앱)
- 대화 상황 15가지(자유 대화, 카페·식당·공항·호텔·쇼핑·병원·전화, 회의·면접, 토론, 단어장 복습, 직접 입력), 수준(초·중·고급), 교정 방식(매번/끝나고/교정 없음), 한국어 설명 옵션은 음성 튜터와 다른 앱 요청문에 함께 쓰입니다.
- **음성으로 바로 대화 시작**(Gemini 키 필요): 한 번 누르면 마이크 허용 → 연결 → 튜터가 먼저 인사하고 질문합니다. 그다음은 그냥 말하면 됩니다. 화면에 상태(연결 중·듣는 중·튜터가 말하는 중·다시 연결 중), 대화 받아쓰기(내 말 오른쪽, 튜터 왼쪽), **교정 카드**(원래 문장 → 고친 문장 + 한국어 설명, 단어장 저장)가 나옵니다. 일시정지·끝내기 버튼이 있고, 대화 중에는 화면이 꺼지지 않습니다. 이 앱의 다른 탭으로 가면 대화가 끝나고, 다른 앱으로 가거나 화면을 끄면 잠시 멈췄다가 돌아오면 이어집니다(3분 넘게 비우면 끝남).
- 대화 중에는 카드가 화면(머리글과 아래 탭 사이)에 꼭 맞게 바뀌어 상태·대화·버튼이 모두 보이고, 대화 내용만 스크롤됩니다. 위로 올려 지난 말을 읽는 동안에는 새 말이 와도 끌어내리지 않습니다.
- **말 끊기** 버튼: 튜터가 말하는 중에 누르면 바로 멈추고 내 차례가 됩니다(Gemini Live·기본 음성 모드 모두). 끊은 답의 나머지(듣지 못한 말)는 대화 내용에 쓰지 않습니다.
- **말로 끊기**(기본 켜짐, Gemini Live): 튜터가 말하는 중에 내가 말하면 튜터가 멈춥니다. 이어폰이 가장 확실하고, 이어폰 없이 스피커로도 됩니다. 스피커일 때는 튜터 목소리가 마이크로 다시 들어오므로, 튜터가 말하는 동안에는 마이크 소리를 붙잡아 두고 **튜터 목소리의 메아리보다 확실히 크고 0.2초 넘게 이어지는 소리(= 내 목소리)**일 때만 직전 0.3초와 함께 보냅니다. 메아리가 얼마나 들어오는지는 내가 조용히 듣던 튜터 차례(첫인사 등)에서 저절로 배우며, 휴대폰의 에코 제거가 메아리를 줄여 줍니다. 잘못 열린 것 같으면(내 말 받아쓰기가 없거나 튜터 말을 되풀이함) 점점 더 깐깐해지고, 한 대화에서 세 번이면 그 대화는 **말 끊기** 버튼으로만 끊고 화면에 알려 줍니다. 휴대폰마다 다르니 튜터가 저절로 자꾸 끊기면 **말로 끊기**를 끄세요. 연결은 약 10분마다 바뀌지만 대화 흐름을 이어서 자동으로 다시 연결합니다.
- Gemini Live를 쓸 수 없으면(오늘 무료 한도 초과, 모델 없음, 연결 실패, 브라우저 미지원) 자동으로 **기본 음성 모드**(브라우저 음성 인식 → Gemini 글 답변 → 기기 음성으로 읽기)로 이어 갑니다. 한도 초과·모델 없음·연결 설정 거부처럼 다시 해도 같은 실패는 그날(미국 태평양 시간 자정까지) 기억해 바로 기본 음성 모드로 시작합니다. 기본 음성 모드는 한쪽씩 말합니다(튜터가 답을 읽는 동안에는 듣지 않고, 다 읽으면 저절로 다시 듣기 시작).
- **단어 뜻 보기**: 대화 중에도 대화 내용의 영어 단어를 **길게 누르면** 뜻 창이 열립니다(튜터·내 말·교정 카드 모두). 뜻 창의 **발음**을 누르면 그 소리가 대화에 섞이지 않게 대화를 잠시 멈췄다가, 창을 닫으면 이어 갑니다. 대화가 끝나면 단어를 그냥 눌러도 됩니다.
- 아래의 **다른 앱으로 연습**과 **앱의 음성 모드로 바로 말하기**는 접혀 있습니다. 제목을 누르면 펼쳐집니다. Gemini 키가 없는 기기(자녀 폰 등)에서는 **다른 앱으로 연습**을 펼쳐 둡니다(키를 넣으면 접힘).
- **다른 앱으로 연습**: **공유로 보내기** → 목록에서 ChatGPT 또는 Gemini 선택. 목록에 없으면 **복사하고 열기**(ChatGPT는 요청문이 자동으로 보내지고, Gemini는 입력창에 들어갑니다. 안 들어가면 입력창을 길게 눌러 붙여넣기).
- **Gemini Live 열기**: Gemini 앱의 Live 화면을 바로 엽니다. Live는 요청문을 받을 수 없으므로 화면에 보이는 첫 문장(설정에 맞춰 만들어짐)을 소리 내어 말하세요. (안드로이드) ChatGPT를 휴대폰의 기본 디지털 어시스턴트 앱으로 설정해 두면(한 번만) 전원(측면) 버튼을 길게 눌러 바로 ChatGPT 음성 대화를 열 수 있습니다. 아이폰은 설정 → 동작 버튼 → **단축어**(또는 **제어**)에서 ChatGPT의 음성 대화 기능을 고르면 동작 버튼을 길게 눌러 열 수 있습니다(ChatGPT 앱 필요, 메뉴 이름은 버전에 따라 다를 수 있음).
- "대화 중에 쓰는 요청" 버튼(더 쉽게, 틀린 것 정리, 세션 끝내고 리뷰 등)을 누르면 영어 문장이 복사됩니다.

### 사전
- 영어를 치면 영→한, 한글을 치면 한→영으로 자동 전환. 마이크 버튼 옆 `EN/한`으로 음성 검색 언어를 바꿉니다.
- 무료 소스: 영영 풀이·발음(Free Dictionary API), 한국어 뜻(MyMemory 번역 메모리), 한→영 풀이(위키낱말사전), 이미지(Openverse 자유 이용 이미지).
- 이미지는 **이미지 보기**를 눌렀을 때만 찾습니다. 한국어로 찾았으면 그때까지 나온 영어 단어(AI 풀이 → 무료 번역 후보)로 찾습니다.
- **Gemini 키를 넣으면** 품사별 한국어 뜻·뉘앙스·예문(영/한)·학습 팁이 담긴 AI 사전 항목이 나옵니다(주요 뜻 3개까지).
  - AI 풀이는 받는 대로 첫 뜻부터 보이고, 그동안 무료 사전 결과도 아래에 함께 나옵니다. 실패하면 받은 데까지 두고 **다시 시도** 버튼을 보여 줍니다.
  - 한 번 찾은 단어는 기기에 저장되어 다음에는 바로 나옵니다(**저장된 풀이** 표시). **새로 풀이**를 누르면 다시 만듭니다. OTT 단어 뜻·AI 해설도 같은 방식으로 저장됩니다.

### 번역
- **텍스트**: 입력한 글의 언어를 보고 방향을 자동으로 맞춥니다. 영어 결과의 단어를 누르면 뜻이 나옵니다.
- **실시간 통역**: "한국어로 말하기" 또는 "Speak English"를 누르고 말하면 문장이 끝날 때마다 번역됩니다. "소리로 읽기"를 켜면 읽는 동안 듣기를 잠시 멈춰 자기 소리를 다시 인식하지 않습니다. 약 30초 동안 말이 없으면 자동으로 멈춥니다.
- **녹음**(녹음 번역): 녹음 후 재생·WAV 저장이 가능하고, 받아쓰기·번역은 Gemini 키가 있어야 합니다.
- **사진**(사진 번역, Gemini 키 필요): **카메라로 찍기**를 누르면 휴대폰 카메라 앱이 열리고, **사진 고르기**는 갤러리·파일에서 고릅니다. (안드로이드) 갤러리·화면 캡처에서 **공유 → English Helper**로 보내도 바로 번역합니다.
  - 메뉴판·안내문·책·화면 캡처의 글자를 읽는 순서대로 문단·줄·메뉴·표지판 단위로 묶어 블록마다 번역합니다(영어 등 다른 언어 → 한국어, 한국어 → 영어). 잘 안 보이는 글자는 지어내지 않고 [?]로 표시합니다.
  - 받는 대로 블록이 하나씩 나옵니다. 영어 단어를 누르면 뜻이 나오고, 블록마다 읽기·복사·단어장 저장, 알아 두면 좋은 영어 표현(최대 5개), 전체 복사가 있습니다. 결과는 번역 기록에 '사진'으로 남습니다.
  - 블록마다 어느 언어인지 함께 받습니다. 읽기·단어장 저장·단어 누르기는 영어가 있는 블록(영어 원문, 또는 한국어 원문의 영어 번역)에만 있고, 일본어·중국어·베트남어처럼 다른 언어 블록은 한국어 번역과 복사만 있습니다. '출구 Exit'처럼 두 언어로 쓴 안내판은 언어마다 따로 나옵니다.
  - 잘못 읽은 글자가 있으면 **글자 고쳐서 다시 번역**을 누르세요. 읽은 글이 텍스트 칸에 들어가니 고친 뒤 번역하기를 누르면 됩니다. 한국어 사진이면 한 → 영, 그 밖의 언어(영어·일본어 등)는 영 → 한 방향으로 맞춰지고, 다른 언어도 Gemini가 한국어로 옮깁니다(번역 기록을 눌러 다시 번역할 때도 같음).
  - Gemini로 보내는 것은 사진과 요청문뿐입니다. 사진은 기기 안에서 방향을 바로잡고 긴 변 2048px 정도의 JPEG(보통 1MB 안팎)로 줄여 보냅니다. 아주 큰 사진(5천만~2억 화소)도 처음부터 줄여서 열어 메모리를 아낍니다. (안드로이드) 크롬이 열지 못하는 HEIF 사진은 원본 그대로(14MB까지) 보냅니다.
  - 화면 캡처는 글자가 작아지지 않게 너비를 1080px까지 남깁니다. 세로로 아주 긴 스크롤 캡처는 위에서부터 조금씩(80px) 겹치게 높이 3000px 이하의 조각으로 잘라(최대 6조각) 차례로 함께 보내고, Gemini에는 한 장의 캡처라고 알려 겹친 줄은 한 번만 읽게 합니다. 6조각보다 길면 6조각에 맞게 줄여 보내며, 글자가 작아 잘못 읽을 수 있다고 화면에 알려 줍니다(그럴 때는 나눠서 캡처하세요).
  - 큰 사진을 보내다 시간이 오래 걸리면(사진이 크거나 연결이 느릴 때) 다시 보내지 않고 알려 줍니다. **다시 시도**를 누르면 준비해 둔 사진(조각)을 그대로 다시 보냅니다.
  - 책처럼 저작권이 있는 긴 글을 그대로 옮기는 것이 막히면, 자동으로 한 번 더 물어 원문 대신 줄인 번역·요약을 보여 줍니다. 이때는 원문이 아니라서 블록마다 복사만 있습니다.
  - 휴대폰 자체 기능으로도 사진 속 글자를 번역할 수 있습니다(키 불필요): 갤럭시 카메라에서 글자를 비추면 나오는 **T(텍스트)** 버튼 → 번역, 또는 홈 버튼(내비게이션 바)을 길게 눌러 **서클 투 서치** → 번역. 아이폰은 카메라·사진 앱의 **텍스트 인식(라이브 텍스트)** → 번역, 아이폰 17은 **카메라 컨트롤**을 길게 눌러 **시각 지능** → 번역. 휴대폰·버전에 따라 이름이 다를 수 있습니다. 웹앱은 휴대폰의 이런 글자 인식·번역 기능을 직접 불러 쓸 수 없어서, 이 앱은 사진을 Gemini로 보내 읽습니다.

### OTT 듣기 도우미

**방금 뭐라고?** — 평소처럼 자막 없이 보다가, 못 알아들은 대사가 있을 때만 씁니다. 자막 파일을 미리 구할 필요가 없습니다.

1. 넷플릭스·웨이브·디즈니+를 TV나 휴대폰 스피커로 틀고, OTT 탭에서 **듣기 시작**을 누릅니다 (처음 한 번 마이크 권한 허용). 소리 막대가 움직이면 잘 듣고 있는 것입니다.
2. 대사를 놓치면 **방금 뭐라고?**를 누릅니다. 1초 더 들어 말하던 대사를 끝까지 담은 뒤, 최근 10·20·30초(기본 20초)를 Gemini가 받아쓰고 해석합니다. 마지막 1~3개 대사의 영어(안 들린 단어는 [inaudible]), 한국어 해석, 슬랭·숙어·구동사·연음(gonna, wanna 등) 설명이 나오는 대로 바로 보입니다. 단어를 누르면 뜻이 나오고, 대사·표현을 단어장에 저장하거나 읽어 볼 수 있습니다.
3. **느리게 다시 듣기**는 받아 둔 소리를 0.75배로 이 기기에서 바로 재생합니다. Gemini 키가 없거나 무료 한도를 다 썼을 때도 됩니다 (받아쓰기·해석은 무료 Gemini 키가 필요). 다시 듣기·읽기 소리가 휴대폰 스피커로 나가는 동안에는 그 소리가 다음 질문에 섞이지 않게 잠시 담지 않습니다.
4. 영화·드라마 대사를 그대로 옮기는 것이 저작권 보호로 막히면, 자동으로 한 번 더 물어 정확한 대사 대신 쉬운 영어 요지와 해석을 보여 줍니다.

알아 둘 점:
- **이 앱이 화면에 떠 있어야 듣습니다.** 휴대폰으로 볼 때는 안드로이드 **분할 화면**이나 넷플릭스 **PIP(작은 창)**로 함께 띄우세요. 아이폰은 분할 화면이 없고, 같은 아이폰에서 넷플릭스를 틀고 듣기를 켜면 넷플릭스 소리가 멈출 수 있으니 TV 등 다른 기기로 볼 때 쓰세요. 세로가 짧은 분할 화면에서는 안내 문구를 숨기고 최근 결과와 큰 버튼만 보이는 간단 배치로 바뀝니다. 듣는 동안에는 화면이 꺼지지 않습니다.
- **이어폰을 쓰면 마이크가 소리를 듣지 못합니다** (웹 앱은 넷플릭스 같은 다른 앱의 소리를 직접 가져올 수도 없습니다). 이때는 아래 **이어폰으로 볼 때**를 쓰거나, 안드로이드 **실시간 자막(Live Caption)**을 켜세요. 실시간 자막은 휴대폰에서 나오는 영상 소리에 자막을 달아 주고 이어폰을 쓰거나 소리를 꺼도 됩니다(휴대폰 설정에서 '실시간 자막' 검색, 갤럭시는 볼륨 버튼 창에서도 켬. 기종·앱마다 다를 수 있음). 아이폰은 설정 → 손쉬운 사용 → **실시간 자막**입니다.
- 스피커 소리를 그대로 듣기 위해 에코 제거·잡음 제거·자동 음량을 끄고 녹음합니다(켜면 안드로이드가 통화 모드로 바뀌어 넷플릭스 소리가 작아지거나 지워짐). 5초 넘게 소리가 거의 없으면 "볼륨을 키우거나 휴대폰을 스피커 가까이" 안내가 뜹니다.
- 듣는 동안 소리는 **이 기기 메모리에만 최근 45초**가 남고 계속 지워집니다. 버튼을 누를 때만 그 구간(16kHz WAV, 30초 ≈ 1MB)이 Google Gemini로 전송되며, 무료 등급에서는 Google이 서비스 개선에 쓸 수 있습니다. 정지를 누르거나 다른 탭으로 가면 마이크를 끄고 보관하던 소리를 지웁니다.
- 음악·효과음이 크거나 여러 사람이 겹쳐 말하면 틀릴 수 있습니다. 결과 아래의 확신 정도(잘 들림/일부 불확실/잘 안 들림)를 참고하세요.

**이어폰으로 볼 때** — 마이크가 영상 소리를 못 들어도 쓸 수 있습니다 (Gemini 키 필요, 듣기를 켜지 않아도 됨).
- **들린 대로 말하기**: 영상을 잠깐 멈추고 버튼을 누른 뒤, 들린 소리를 흉내 내듯 따라 말하고 다시 누릅니다(최대 15초). 뭉개지거나 한국어처럼 들려도 괜찮습니다. Gemini가 내 소리가 어떻게 들렸는지와 함께 **가장 그럴듯한 영어 대사**(애매하면 후보 2~3개), 한국어 해석, 표현, 왜 그렇게 들렸는지(연음·축약·t가 r처럼 들리는 소리 등)를 알려 줍니다. 듣기가 켜져 있으면 끄고 녹음합니다(마이크 두 개를 함께 열면 안드로이드에서 서로 끊김).
- **적어서 묻기**: 들린 소리를 영어든 한글이든 적으면(예: 아이 고나 웨더 잇) 같은 방식으로 짐작합니다.
- **작품·장면(선택)**에 "프렌즈 시즌1"처럼 적으면 더 잘 짐작합니다(앱을 닫으면 지워짐). 다른 탭으로 가면 녹음과 요청을 멈춥니다.

**자막 파일로 따라가기 (선택)** — 자막 파일이 있으면 OTT 탭 아래쪽의 접힌 칸을 열어 씁니다.

1. 보고 있는 작품·회차의 **영어 자막 파일**(SRT, VTT, SMI, TTML/DFXP)을 불러옵니다. 한글 자막을 함께 넣으면 해석이 붙고, 영어·한글이 함께 든 SMI는 영어 칸에만 넣으면 됩니다. 국내 SMI에 흔한 EUC-KR(CP949) 인코딩도 읽습니다.
2. **시간 맞추기**: 넷플릭스 재생과 함께 ▶를 누르거나, 시계를 눌러 재생 바의 시간을 입력합니다. 가장 정확한 방법은 첫 대사가 나올 때 "전체 대사"에서 그 줄을 눌러 **이 대사로 시간 맞추기**입니다. 배속 시청(0.5~1.5배)도 맞출 수 있습니다.
3. 놓친 대사가 있으면 넷플릭스 ⟲10과 함께 **10초 되감기 · 대사 보기**(5·10·15·20·30초 선택). 각 대사에서 읽기·천천히·해석·저장·AI 해설을 쓸 수 있고, 단어를 누르면 뜻이 나옵니다.
4. **영어 대사 숨기기**를 켜면 평소엔 대사를 가리고 되감기 때만 보여 줍니다(듣기 연습). 재생 중에는 화면이 꺼지지 않습니다.
5. 자막은 기기 안의 보관함에 저장되고 마지막 위치를 기억합니다.

> 자막 파일은 직접 구한 개인 학습용 파일을 사용하세요. 자막의 저작권은 제작사에 있으므로 공유·배포하지 마세요. 앱에 든 샘플 자막은 이 프로젝트에서 직접 쓴 대화입니다.

### 설정
- **Gemini API 키(선택)**: [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 등급 키를 발급받아 넣습니다. 앱 안 음성 영어회화와 AI 사전·번역·받아쓰기·사진 번역·해설에 쓰입니다. "연결 테스트"와 "모델 목록 확인"을 지원하며, 기본 모델은 빠른 `gemini-3.5-flash-lite`입니다(음성 대화는 Live 모델 `gemini-3.8-live`). Gemini API 약관상 만 18세 이상만 쓸 수 있고, 무료 등급에서는 입력 내용(음성 대화 포함)이 Google의 서비스 개선에 쓰이고 검토자가 볼 수 있습니다. 키는 기기마다 따로 넣고, 같은 프로젝트의 키는 하루 한도를 함께 씁니다(위 **여러 기기·가족과 함께 쓰기**).
- **무료 번역 이메일(선택)**: MyMemory의 하루 무료 한도(익명 약 5,000자)를 약 50,000자로 늘립니다.
- 영어 음성·읽기 속도, 앱 설치, 모든 데이터 지우기.

## 개인정보

- 설정(Gemini 키 포함), 단어장, 기록, 자막 보관함은 **이 기기의 브라우저 저장소에만** 저장되고 별도 서버로 보내지 않습니다. 휴대폰 공간이 부족해도 지워지지 않게 앱을 열 때 브라우저에 "계속 보관"을 요청합니다(묻는 창 없음, 허용 여부는 브라우저가 정함).
- 검색어와 번역할 글은 해당 기능의 외부 서비스(Free Dictionary API, MyMemory, Wiktionary, Openverse, Gemini를 켠 경우 Google)로 전송됩니다.
- 음성 인식은 휴대폰 브라우저의 음성 인식 기능을 사용합니다(안드로이드 크롬은 Google, 아이폰은 Apple의 Siri·받아쓰기).
- AI 회화의 음성 대화를 쓰면 마이크 소리와 대화 내용이 Google Gemini(Live API)로 전송됩니다. 대화 중에만 마이크를 쓰고, 끝내거나 다른 앱으로 오래 가면 마이크와 연결을 닫습니다.
- OTT "방금 뭐라고?"는 듣는 동안 최근 45초 소리만 메모리에 두고 계속 지우며, 버튼을 누른 구간만 Gemini로 보냅니다. "들린 대로 말하기·적어서 묻기"는 내 녹음·글만 보냅니다. 소리는 저장하지 않습니다.
- 사진 번역은 번역할 때만 그 사진(줄인 JPEG, 긴 캡처는 그 조각들)을 Google Gemini로 보냅니다. 사진은 앱에 저장하지 않습니다(다른 앱에서 공유받은 사진은 번역 화면이 꺼내면서 바로 지움). 무료 등급에서는 Google이 서비스 개선에 쓸 수 있으니 주민등록증·카드처럼 민감한 정보가 담긴 사진은 보내지 마세요. 읽은 글은 번역 기록에 남습니다(기록 지우기로 삭제).

## 개발

```bash
npm test            # 단위 테스트 (Node 20 이상, 외부 패키지 없음)
npm start           # http://localhost:8080 에서 실행
```

- localhost에서는 서비스 워커를 끄고 실행합니다(수정 사항이 바로 보이도록). 켜서 확인하려면 `http://localhost:8080/?sw=1`.
- 마이크·음성 인식은 HTTPS 또는 localhost에서만 동작합니다.
- **새 파일을 추가하면 `sw.js`의 `ASSETS` 목록에도 넣어야 합니다** (빠지면 `tests/precache.test.js`가 실패).
- 코드 형식: Prettier (`.prettierrc.json`).

```
index.html, manifest.webmanifest, sw.js   앱 껍데기·설치 정보·오프라인 캐시·공유받기(글·사진)
css/app.css                               스타일 (밝은/어두운 테마)
```
