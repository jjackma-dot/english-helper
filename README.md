# English Helper

휴대폰(안드로이드 우선)에 설치해서 쓰는 영어 학습 웹앱(PWA)입니다. 빌드 과정 없이 HTML·CSS·JavaScript만으로 만들었고, GitHub Pages로 무료 배포합니다.

| 탭 | 기능 |
| --- | --- |
| **AI 회화** | 상황·수준·교정 방식을 고르면 영어 튜터 요청문을 만들어 휴대폰의 **ChatGPT·Gemini 앱**으로 보냄 (공유하기 또는 복사 후 앱 열기) |
| **사전** | 한영·영한 자동 판별, 한국어 뜻, 영영 풀이, 예문(+해석), **발음 듣기**(원어민 음성·TTS·느리게), **이미지 검색**(필요할 때만), 음성 검색, 네이버·다음·Cambridge·YouGlish 바로가기 |
| **번역** | 텍스트 번역, **실시간 통역**(말하면 문장마다 바로 번역, 소리로 읽기), **녹음 번역**(최대 5분 녹음 → 받아쓰기·번역, WAV 저장) |
| **OTT** | 자막 없이 보다가 **"방금 뭐라고?"** 한 번 → 최근 10~30초 대사 받아쓰기·해석·표현 설명(Gemini), 느리게 다시 듣기 · (선택) 자막 파일로 따라가며 되감기 |
| **단어장** | 사전·번역·OTT에서 저장한 단어와 대사, 뜻 가리기, AI 튜터 복습 연결, JSON 내보내기/가져오기 |

## 먼저 알아 둘 점 (기술적 제약)

- **넷플릭스·웨이브 앱은 다른 앱이 화면에 버튼을 띄우거나, 재생을 되감거나, 자막을 읽을 수 없습니다** (DRM과 앱 간 보안 격리). 그래서 OTT 기능은 **휴대폰 마이크로 스피커 소리를 듣는 방식**("방금 뭐라고?")이 기본이고, 자막 파일을 불러와 재생 시간에 맞춰 따라가는 방식은 선택입니다.
- **ChatGPT·Gemini 앱을 직접 조종할 수는 없습니다.** 대신 튜터 요청문을 안드로이드 공유 시트로 보내거나, 복사한 뒤 앱을 열어 줍니다(앱에서 입력창을 길게 눌러 붙여넣기). 음성 대화는 요청문을 보낸 뒤 앱의 음성 모드(ChatGPT 음성 모드, Gemini Live)를 쓰면 됩니다.
- 사전·번역·이미지는 **인터넷이 필요**합니다. 앱 화면과 저장한 자막·단어장은 오프라인에서도 열립니다.

## 배포 (GitHub Pages)

1. 이 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다 (한 번만).
2. 변경 사항을 `main` 브랜치에 합치면 `.github/workflows/pages.yml`이 테스트를 돌린 뒤 자동 배포합니다.
3. 주소: **https://jjackma-dot.github.io/english-helper/**

배포할 때 버전 표시(`__BUILD__`)가 "앱 파일이 마지막으로 바뀐 날짜-내용 해시"(예: `20261008-1a2b3c4d`)로 바뀝니다. 앱 파일이 실제로 바뀐 경우에만 버전이 달라져서, 이미 설치한 휴대폰에 "새 버전이 있습니다 → 업데이트" 안내가 뜹니다. README·테스트만 고친 배포에서는 안내가 뜨지 않습니다.

## 휴대폰에 설치 (안드로이드 크롬)

1. 크롬으로 위 주소를 엽니다.
2. 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가** (화면 위쪽 "앱 설치" 버튼이 보이면 그걸 눌러도 됩니다).
3. 설치하면 다른 앱의 **공유 → English Helper**로 단어(→ 사전)나 문장(→ 번역)을 바로 보낼 수 있고, 앱 아이콘을 길게 누르면 사전·번역·OTT 바로가기가 나옵니다.
4. 처음 마이크를 쓸 때 권한을 허용하세요.

## 기능별 사용법

### AI 회화 (ChatGPT·Gemini 튜터)
- 대화 상황 15가지(자유 대화, 카페·식당·공항·호텔·쇼핑·병원·전화, 회의·면접, 토론, 단어장 복습, 직접 입력), 수준(초·중·고급), 교정 방식(매번/끝나고/교정 없음), 한국어 설명, 음성 대화용 옵션.
- **공유로 보내기** → 목록에서 ChatGPT 또는 Gemini 선택. 목록에 없으면 **복사하고 열기** → 입력창을 길게 눌러 붙여넣기.
- "대화 중에 쓰는 요청" 버튼(더 쉽게, 틀린 것 정리, 세션 끝내고 리뷰 등)을 누르면 영어 문장이 복사됩니다.

### 사전
- 영어를 치면 영→한, 한글을 치면 한→영으로 자동 전환. 마이크 버튼 옆 `EN/한`으로 음성 검색 언어를 바꿉니다.
- 무료 소스: 영영 풀이·발음(Free Dictionary API), 한국어 뜻(MyMemory 번역 메모리), 한→영 풀이(위키낱말사전), 이미지(Openverse 자유 이용 이미지).
- 이미지는 **이미지 보기**를 눌렀을 때만 찾습니다. 한국어로 찾았으면 그때까지 나온 영어 단어(AI 풀이 → 무료 번역 후보)로 찾습니다.
- **Gemini 키를 넣으면** 품사별 한국어 뜻·뉘앙스·예문(영/한)·학습 팁이 담긴 AI 사전 항목이 나옵니다(주요 뜻 3개까지).
  - AI 풀이는 받는 대로 첫 뜻부터 보이고, 그동안 무료 사전 결과도 아래에 함께 나옵니다. 실패하면 받은 데까지 두고 **다시 시도** 버튼을 보여 줍니다.
  - 한 번 찾은 단어는 기기에 저장되어 다음에는 바로 나옵니다(**저장된 풀이** 표시). **새로 풀이**를 누르면 다시 만듭니다. OTT 단어 뜻·AI 해설도 같은 방식으로 저장됩니다.

### 번역
- **텍스트**: 입력한 글의 언어를 보고 방향을 자동으로 맞춥니다. 영어 결과의 단어를 누르면 뜻이 나옵니다.
- **실시간 통역**: "한국어로 말하기" 또는 "Speak English"를 누르고 말하면 문장이 끝날 때마다 번역됩니다. "소리로 읽기"를 켜면 읽는 동안 듣기를 잠시 멈춰 자기 소리를 다시 인식하지 않습니다. 약 30초 동안 말이 없으면 자동으로 멈춥니다.
- **녹음 번역**: 녹음 후 재생·WAV 저장이 가능하고, 받아쓰기·번역은 Gemini 키가 있어야 합니다.

### OTT 듣기 도우미

**방금 뭐라고?** — 평소처럼 자막 없이 보다가, 못 알아들은 대사가 있을 때만 씁니다. 자막 파일을 미리 구할 필요가 없습니다.

1. 넷플릭스·웨이브·디즈니+를 TV나 휴대폰 스피커로 틀고, OTT 탭에서 **듣기 시작**을 누릅니다 (처음 한 번 마이크 권한 허용). 소리 막대가 움직이면 잘 듣고 있는 것입니다.
2. 대사를 놓치면 **방금 뭐라고?**를 누릅니다. 1초 더 들어 말하던 대사를 끝까지 담은 뒤, 최근 10·20·30초(기본 20초)를 Gemini가 받아쓰고 해석합니다. 마지막 1~3개 대사의 영어(안 들린 단어는 [inaudible]), 한국어 해석, 슬랭·숙어·구동사·연음(gonna, wanna 등) 설명이 나오는 대로 바로 보입니다. 단어를 누르면 뜻이 나오고, 대사·표현을 단어장에 저장하거나 읽어 볼 수 있습니다.
3. **느리게 다시 듣기**는 받아 둔 소리를 0.75배로 이 기기에서 바로 재생합니다. Gemini 키가 없거나 무료 한도를 다 썼을 때도 됩니다 (받아쓰기·해석은 무료 Gemini 키가 필요). 다시 듣기·읽기 소리가 휴대폰 스피커로 나가는 동안에는 그 소리가 다음 질문에 섞이지 않게 잠시 담지 않습니다.
4. 영화·드라마 대사를 그대로 옮기는 것이 저작권 보호로 막히면, 자동으로 한 번 더 물어 정확한 대사 대신 쉬운 영어 요지와 해석을 보여 줍니다.

알아 둘 점:
- **이 앱이 화면에 떠 있어야 듣습니다.** 휴대폰으로 볼 때는 안드로이드 **분할 화면**이나 넷플릭스 **PIP(작은 창)**로 함께 띄우세요. 세로가 짧은 분할 화면에서는 안내 문구를 숨기고 최근 결과와 큰 버튼만 보이는 간단 배치로 바뀝니다. 듣는 동안에는 화면이 꺼지지 않습니다.
- **이어폰을 쓰면 마이크가 소리를 듣지 못합니다.** 이때는 넷플릭스 ⟲10초 + 영어 자막 잠깐 켜기나, 안드로이드 **실시간 자막(Live Caption)**(볼륨 버튼 → … → 실시간 자막, 앱에 따라 막힐 수 있음)을 쓰세요.
- 스피커 소리를 그대로 듣기 위해 에코 제거·잡음 제거·자동 음량을 끄고 녹음합니다(켜면 안드로이드가 통화 모드로 바뀌어 넷플릭스 소리가 작아지거나 지워짐). 5초 넘게 소리가 거의 없으면 "볼륨을 키우거나 휴대폰을 스피커 가까이" 안내가 뜹니다.
- 듣는 동안 소리는 **이 기기 메모리에만 최근 45초**가 남고 계속 지워집니다. 버튼을 누를 때만 그 구간(16kHz WAV, 30초 ≈ 1MB)이 Google Gemini로 전송되며, 무료 등급에서는 Google이 서비스 개선에 쓸 수 있습니다. 정지를 누르거나 다른 탭으로 가면 마이크를 끄고 보관하던 소리를 지웁니다.
- 음악·효과음이 크거나 여러 사람이 겹쳐 말하면 틀릴 수 있습니다. 결과 아래의 확신 정도(잘 들림/일부 불확실/잘 안 들림)를 참고하세요.

**자막 파일로 따라가기 (선택)** — 자막 파일이 있으면 OTT 탭 아래쪽의 접힌 칸을 열어 씁니다.

1. 보고 있는 작품·회차의 **영어 자막 파일**(SRT, VTT, SMI, TTML/DFXP)을 불러옵니다. 한글 자막을 함께 넣으면 해석이 붙고, 영어·한글이 함께 든 SMI는 영어 칸에만 넣으면 됩니다. 국내 SMI에 흔한 EUC-KR(CP949) 인코딩도 읽습니다.
2. **시간 맞추기**: 넷플릭스 재생과 함께 ▶를 누르거나, 시계를 눌러 재생 바의 시간을 입력합니다. 가장 정확한 방법은 첫 대사가 나올 때 "전체 대사"에서 그 줄을 눌러 **이 대사로 시간 맞추기**입니다. 배속 시청(0.5~1.5배)도 맞출 수 있습니다.
3. 놓친 대사가 있으면 넷플릭스 ⟲10과 함께 **10초 되감기 · 대사 보기**(5·10·15·20·30초 선택). 각 대사에서 읽기·천천히·해석·저장·AI 해설을 쓸 수 있고, 단어를 누르면 뜻이 나옵니다.
4. **영어 대사 숨기기**를 켜면 평소엔 대사를 가리고 되감기 때만 보여 줍니다(듣기 연습). 재생 중에는 화면이 꺼지지 않습니다.
5. 자막은 기기 안의 보관함에 저장되고 마지막 위치를 기억합니다.

> 자막 파일은 직접 구한 개인 학습용 파일을 사용하세요. 자막의 저작권은 제작사에 있으므로 공유·배포하지 마세요. 앱에 든 샘플 자막은 이 프로젝트에서 직접 쓴 대화입니다.

### 설정
- **Gemini API 키(선택)**: [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 등급 키를 발급받아 넣습니다. "연결 테스트"와 "모델 목록 확인"을 지원하며, 기본 모델은 최신 Flash 모델을 가리키는 `gemini-flash-latest`입니다. 무료 등급에서는 입력 내용이 Google의 서비스 개선에 쓰일 수 있습니다.
- **무료 번역 이메일(선택)**: MyMemory의 하루 무료 한도(익명 약 5,000자)를 약 50,000자로 늘립니다.
- 영어 음성·읽기 속도, 앱 설치, 모든 데이터 지우기.

## 개인정보

- 설정(Gemini 키 포함), 단어장, 기록, 자막 보관함은 **이 기기의 브라우저 저장소에만** 저장되고 별도 서버로 보내지 않습니다.
- 검색어와 번역할 글은 해당 기능의 외부 서비스(Free Dictionary API, MyMemory, Wiktionary, Openverse, Gemini를 켠 경우 Google)로 전송됩니다.
- 음성 인식은 휴대폰 브라우저(크롬)의 음성 인식 기능을 사용합니다.
- OTT "방금 뭐라고?"는 듣는 동안 최근 45초 소리만 메모리에 두고 계속 지우며, 버튼을 누른 구간만 Gemini로 보냅니다. 소리는 저장하지 않습니다.

## 개발

```bash
npm test            # 단위 테스트 (Node 20 이상, 외부 패키지 없음)
npm start           # http://localhost:8080 에서 실행
```

- localhost에서는 서비스 워커를 끄고 실행합니다(수정 사항이 바로 보이도록). 켜서 확인하려면 `http://localhost:8080/?sw=1`.
- 마이크·음성 인식은 HTTPS 또는 localhost에서만 동작합니다.
- **새 파일을 추가하면 `sw.js`의 `ASSETS` 목록에도 넣어야 합니다** (빠지면 `tests/precache.test.js`가 실패).
- 코드 형식: Prettier (`.prettierrc.json`).

```
index.html, manifest.webmanifest, sw.js   앱 껍데기·설치 정보·오프라인 캐시
css/app.css                               스타일 (밝은/어두운 테마)
js/app.js                                 화면 전환, 공유받기, 서비스 워커 등록
js/views/                                 tutor · dictionary · translate · ott(+ott-listen) · wordbook · settings
js/services/                              gemini · translate · dictionary · recorder · listen-buffer · wake-lock (외부 API·녹음·화면 켜짐)
js/lib/                                   순수 로직 (자막 파서, 프롬프트, 시계, WAV, 최근 소리 링 버퍼, API 응답 정리) — 단위 테스트 대상
js/components/word-sheet.js               단어 누르면 뜨는 간단 사전
samples/                                  체험용 자막 (직접 작성)
tests/                                    node:test 단위 테스트
```
